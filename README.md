# Language
Language service for the snippets service

## Framework

[Quarkus](https://quarkus.io/)

Porque este framework? Primero que lo encontre stackoverflow donde un user decia que era bueno y ya por eso es una buena senial, porque las mejores cosas siempre salen de gente random que hace 10 anios hizo un post ahi. Fui a la pagina de quarkus y me compro con las cosas que decia sobre su filosfia de base, que es el reactive manfiesto, y tambien su integracion con kubernetes.
